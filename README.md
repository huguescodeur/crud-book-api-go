REST API in Go

A simple REST API built with Go, focusing on clean code, dependency injection, error handling, and maintainable backend architecture.

Features
RESTful CRUD operations
Clean separation of handlers, services, and database access
Dependency injection
JSON responses and error handling
SQLite database integration
Tech Stack
Language: Go
Database: SQLite
API: REST / HTTP
Getting Started

Clone the repository:

git clone https://github.com/huguescodeur/crud-book-api-go.git
cd <project-directory>

Run the application:

go run main

Purpose

This project demonstrates how to structure and build a maintainable REST API in Go using practical backend development principles.
